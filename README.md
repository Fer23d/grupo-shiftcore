# NaveMae Portal

Portal corporativo central desenvolvido com React + Vite para atuar como hub de acesso aos dominios de produtos, servicos e canais institucionais da empresa.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Configuracao dos links

Os cards do ecossistema ficam configurados no array `ecosystemLinks`, dentro de `src/App.jsx`.

Cada item possui:

- `id`
- `title`
- `description`
- `url`
